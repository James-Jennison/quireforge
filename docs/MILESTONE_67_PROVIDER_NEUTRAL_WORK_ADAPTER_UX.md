# M67 Provider-Neutral Work Adapter UX

## Delivered local surface

M67 adds a lazy Work-lane **Adapters** route over the existing deterministic
local mock-inference catalogue. It displays closed fixture descriptors,
descriptor digests, declared scenario, and the local-fixture privacy and
retention boundary. Choosing a radio option is ephemeral UI state only.

The existing reviewed local mock workflow remains the sole fixture seam. M67
does not add a command, migration, adapter implementation, provider catalogue,
or persistent selection. Its familiar descriptor labels are deliberately marked
fictional and local so they cannot be mistaken for service availability.

## Non-authority guarantee

The route cannot connect, authenticate, store credentials, perform OAuth,
transmit a bundle, retain authored input, enable a tool or retrieval, execute
a model, schedule work, or mutate an external service. When the fixture catalog
cannot be read, the UI reports that no connection was attempted.

Any later live adapter remains separately gated by M61/M62 and a named
implementation decision. M63 continues to consume only a confirmed, expiring,
digest-bound M60 bundle under its existing local-runtime constraints.

## Evidence

Component coverage proves a deterministic descriptor can be selected without a
connect or submit control. TypeScript and Rust checks remain part of the final
M66--M68 validation matrix.
